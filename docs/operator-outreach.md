# Operator discovery — outreach specification

Status: Not sent. No respondents, endorsements, or user commitments.

Target: Kubernetes platform engineers/SREs operating Argo CD or Flux with incident ownership.

Request a 15-minute technical interview about a real API-server or etcd saturation incident, existing APF/controller mitigations, and evidence that reconciliation contributed to load. Request sanitized incident reports or traces only; never ask for cluster credentials, secrets, or production access.

Record each interview: date, organization type (if authorized), cluster and controller versions, observed failure, attribution evidence level (E0-E3), native mitigation outcomes, unacceptable risks, and whether a nonproduction evaluation is acceptable.

Do not interpret social-media likes, opinions, or hypothetical interest as customer validation.
